# Lesson 03 - Practice

Create your 03-practice.html file and add boilerplate HTML to it.

## Problem 1:

Create a paragraph and make the text say "My favorite hobbies:" (this doesn't have to be hobbies, it can be TV Shows, Food, Sports, anything you want)

## Problem 2:

Create an unordered list, with 3-5 list items. You can make the items anything you want.

## Problem 3:

Create another paragraph, with the text saying "What I did today:"

## Problem 4:

Create an ordered list, with 3-5 list items of your own choosing.

## Problem 5:

Add one more list item to the "What I did today" list, and make it a broad category, like "Chores"

## Problem 6:

Nest an unordered list inside the "Chores" list item, and add 3 list items with different types of chores (or whatever category you created)
