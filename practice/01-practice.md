# Lesson 01 - Practice

## Problem 1:

Create an HTML file and use the VS Code Emmet tool to add the boilerplate HTML

## Problem 2:

In the HTML, set the title to say "Lesson 01 - Practice"

## Problem 3:

In the body of the HTML, create an h1 tag and make the text say "Lesson 01 - Practice"

## Problem 4:

After the h1 tag, create a paragraph and add one sentence, with any the text you want.

## Problem 5:

Now, in the same paragraph tag, add a line break after the first sentence, then add a second sentence after the line break, again any text that you want.

## Problem 6:

Add a horizontal rule after the h1 tag and before the paragraph tag.
