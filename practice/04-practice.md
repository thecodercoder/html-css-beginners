# Lesson 04 - Practice

Create your 04-practice.html file and add boilerplate HTML to it.

## Problem 1:

Create a link to a website of your choice, with the text "Check this out!"

## Problem 2:

Add a tool tip when you hover over the link that contains the name of the website.

## Problem 3:

Make the link open in a new browser tab instead of the same one.

## Problem 4:

Add a line break after the first hyperlink, then create a new hyperlink that reads "Contact Me" and will link to sending an email to the email address "me@example.com".

## Problem 5:

Add a line break after the previous hyperlink, then create a new hyperlink that reads "Practice 01" and links to the 01-practice.html file in the same folder, using a relative URL.
