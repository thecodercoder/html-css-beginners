# Lesson 09 - Practice

Create your 09-practice.html file and add boilerplate HTML to it.

## Problem 1:

Make sure you have audio files to use. If you need files and haven't done so already, download the media files from my GitHub here: https://github.com/thecodercoder/html-css-beginners/tree/main/practice/media

And move the files into the "media" folder.

## Problem 2:

In the HTML file, create an audio player, and load the MP3 file in it.

## Problem 3:

Add the player controls so you can click play on the website.

## Problem 4:

Make the audio file muted by default.

## Problem 5:

Make the audio autoplay on load.

## Problem 6:

Make the audio loop.

## Problem 7:

Make the audio player load both the MP3 and OGG files as sources.
