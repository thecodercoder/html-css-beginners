# Lesson 07 - Practice

Create your 07-practice.html file and add boilerplate HTML to it. Title the page "Programming Languages".

## Problem 1:

Create a table with the following header cells:

- Name
- Year Invented
- Creator
- Type of Languauge

In the table tag, add the attribute: border="1"

NOTE: This is a deprecated attribute, and is only suggested as a way to add table borders without using CSS.
