# Lesson 08 - Practice

Create your 08-practice.html file and add boilerplate HTML to it.

## Problem 1:

In the "practice" folder, create a new folder called "media".

If you need video files, download the media files from my GitHub here: https://github.com/thecodercoder/html-css-beginners/tree/main/practice/media

And move the files into the "media" folder.

## Problem 2:

In the HTML file, create a video player, and load the MOV file in it.

## Problem 3:

Size the video player to be 400 pixels wide.

## Problem 4:

Add the player controls so you can click play on the website.

## Problem 5:

Make the video file muted by default.

## Problem 6:

Make the video autoplay on load.

## Problem 7:

Make the video loop.

## Problem 8:

Make the video player load both the MOV and MP4 files as sources.
