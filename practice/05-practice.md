# Lesson 05 - Practice

Create your 05-practice.html file and add boilerplate HTML to it.

## Problem 1:

Get any image that you'd like to work with, and copy it directly into the practice folder.

## Problem 2:

In the HTML file, add an image tag that loads the image file.

## Problem 3:

Set the width to 150 pixels. Make sure the image file is bigger than 150 px wide, otherwise it may look pixelated on the website.

## Problem 4:

Add alt text to the image, describing what the image looks like.
