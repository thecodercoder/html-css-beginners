# Lesson 02 - Practice

In the "practice" folder, create a new file called "02-practice.html" and add boilerplate HTML to it.

Don't forget to use the Live Server extension to load the file so you can check your work as you go!

## Problem 1:

Create a paragraph with text that reads "This is my favorite movie!"

## Problem 2:

In that paragraph, make the word "favorite" bold

## Problem 3:

Create a new paragraph, add text saying "It's called" then add the title of your favorite movie in it. Make the movie title italicized.

## Problem 4:

Add a quote you like from your favorite movie and use the blockquote tag.

## Problem 5:

Add a comment before the first paragraph that contains the text "Favorite Movie"

Also practice using the VS Code shortcut to toggle the comment tags.
