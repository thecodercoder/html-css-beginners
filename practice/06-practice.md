# Lesson 06 - Practice

Create your 06-practice.html file and add boilerplate HTML to it.

## Problem 1:

Create a new form using a "POST" method, leaving the "action" blank.

## Problem 2:

In the form, add an input for an email address, and give it a name and ID of your choosing. Try to follow the naming conventions from the lesson.

## Problem 3:

Add a label for the email textbox that says, "Subscribe with your email."

## Problem 4:

Add placeholder text that reads, "name@example.com"

## Problem 5:

Make the email a required field.

## Problem 6:

Add a submit button that says "Subscribe"

## Problem 7:

Experiment with filling the field with non-email text (e.g. "test") and then submitting, to see what happens.
